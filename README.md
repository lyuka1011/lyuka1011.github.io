# 潚 Siao｜潚然塵外品牌展示網站

## 檔案結構

- `index.html`：潚的個人專業介紹長頁（單欄直向、人物照片保持原始比例）
- `intro/index.html`：個人介紹的網址別名，會回到首頁
- `five-elements/index.html`：「你的五行聲音」概念展示測算頁
- `five-elements/assets/*.mp3`：10 組程序製作的 30 秒**示意聲景**，不是潚本人天語錄音
- `assets/`：使用者提供的人物照片（去除圖示欄）及品牌視覺素材

所有頁面均為可直接以瀏覽器開啟的靜態 HTML。無需安裝 Node.js、npm 或任何付費主機。

## GitHub Pages 部署（需要帳號本人操作）

1. 用 `lyuka1011` 登入 https://github.com ，建立 **Public** repository：`lyuka1011.github.io`（此名稱需完全一致），若已存在則沿用。
2. 將本 ZIP 解壓縮後，**解壓縮資料夾內的所有檔案和資料夾**上傳到儲存庫根目錄（不是把 ZIP 當檔案上傳）。
3. 在 GitHub 該儲存庫的 **Settings → Pages → Build and deployment** 選 `Deploy from a branch`；選 `main`、`/(root)` 後儲存。
4. 部署成功後，預期位置為：
   - 個人介紹 `https://lyuka1011.github.io/`
   - 五行聲音 `https://lyuka1011.github.io/five-elements/`
   - 別名 `https://lyuka1011.github.io/intro/`
5. 如果儲存庫已存在，更新檔案後提交 Commit；下一次部署會自動更新。

上述網址是**預期地址**，只有 GitHub 真正完成 Pages 發布後才會生效。目前沒有替使用者上線或變更 GitHub 帳號設定。

## 重要限制

- 出生資料只在本機瀏覽器參與示範組合切換，不連接正式八字引擎、無後端資料庫。
- 五行過旺、偏弱、缺失、喜用神在正式版必須分開驗證判定；目前是10組劇本範例，並非真實命盤推算。
- `NT$1,390` 為商品規劃價；LINE 登入、金流支付、解鎖、推薦獎勵均為展示，不會實際扣款、登入或發獎勵。
- 課程／個案按鈕展示介紹、複製洽詢訊息；沒有公開官方 LINE 或預約網址就不虛構連結。
- 使用者的琴床人物照片使用去掉左欄圖示的版本；CSS 使用 `width:100%;height:auto` 並保留圖片原始比例。
- α 腦波 8–12 Hz、音檔的可聽頻率、聲景節律是不同概念；未經測試不宣稱可誘發特定腦波或治療睡眠問題。
- 吉凶／五行解讀為傳統命理文化解釋，非科學驗證的個人特質測量。
- 正式商業收款與會員登入不應僅靠靜態 GitHub Pages，需安全後端與符合使用條款的正式商業主機。
