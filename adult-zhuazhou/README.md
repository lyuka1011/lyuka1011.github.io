# 成年人的抓周｜網站進度預覽

這是供夥伴查看目前視覺與操作進度的 GitHub Pages 版本。

- 手機直式分鏡、嬰兒背影插圖與四段字幕。
- 頁首標題沿用內文襯線字體，左右金色飾邊；往下滑時隨頁面離開畫面。
- 場次月曆、每場最多 10 人、額滿場次停用報名。
- 影片與正式報名網址、場次可由線上後台管理，公開頁面每 30 秒同步。
- 主標與字幕使用 SVG 向量文字，保留桌面核定字形。

線上後台：https://adult-zhuazhou-admin.stormypetunia2.chatgpt.site/admin

## 更新方式

桌面專案的 `build_github_preview.py` 可重新產生這個資料夾。
`content.json` 僅包含已公開場次的顯示資料，不包含未公開場次或後台付款人數欄位。
公開頁面直接讀取 Sites 的公開場次 API，不使用 content.json 快照更新名額。
線上後台的管理資料與修改操作須經 ChatGPT 登入及管理員權限檢查。
Python 後台保留在本機供封存參考，後續請使用線上後台。
