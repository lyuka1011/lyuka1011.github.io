# 成年人的抓周｜網站進度預覽

這是供夥伴查看目前視覺與操作進度的 GitHub Pages 版本。

- 手機直式分鏡、嬰兒背影插圖與四段字幕。
- 頁首標題沿用內文襯線字體，左右金色飾邊；往下滑時隨頁面離開畫面。
- 場次月曆、每場最多 10 人、額滿場次停用報名。
- 影片與正式報名網址仍待補上。

## 更新方式

桌面專案的 `build_github_preview.py` 可重新產生這個資料夾。
`content.json` 僅包含已公開場次的顯示資料，不包含未公開場次或後台付款人數欄位。
線上預覽讀取發布時的資料；桌面後台修改後須重新產生並發布。
Python 後台保留在本機，GitHub Pages 不執行它。
